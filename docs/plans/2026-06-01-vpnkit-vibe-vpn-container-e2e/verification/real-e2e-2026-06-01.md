## Fixes made during real run

Two runner/runtime issues were found and fixed before the passing run:

1. `COMPOSE_PROJECT_NAME` was derived from an uppercase timestamp (`T`/`Z`), which Docker Compose rejected. The e2e script now lowercases the compose project name after run-id normalization.
2. sing-box 1.13.11 required `ENABLE_DEPRECATED_MISSING_DOMAIN_RESOLVER=true` for the current config format. This env var was added next to the existing legacy DNS compatibility flag.
3. Success cleanup initially left the profile-gated `ovpn-client-test` container/image behind. Cleanup now runs `docker compose --profile test down ...` so test-profile services are removed before local image cleanup.
4. The runner log pipeline was adjusted to redact before writing to both console and the per-run log file.
